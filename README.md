## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- Rust 1.75+
- Python 3.11+
- Docker & Kubernetes
- PostgreSQL 16+
- Redis 7+

### Installation

```bash
# Clone the repository
git clone https://github.com/harikapadia999/quantumtrade-2030.git
cd quantumtrade-2030

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Start development environment
docker-compose up -d

# Run migrations
npm run migrate

# Start the application
npm run dev
```
